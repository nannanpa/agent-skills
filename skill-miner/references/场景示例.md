# 场景示例（skill-miner 参考文件）

> 正文只留一句话摘要，这里是三类完整展开 ＋ 一个反例 ＋ 边界情形清单。
> **用途**：拿不准某个情形算不算候选时查这里。示例均为虚构通用场景，不含真实机构、人名或内部数据。

---

## 示例一 · 文档/材料写作类

用户在同一周内让 AI 起草过两份同类材料，第二次时说"跟上次那个格式一样"。

- **扫描**：场景重发✓（两份同类材料，且第二次明确要求对齐上一次）；步骤决策点✓（取素材→定口径→套骨架→核对引语，每步都有判断）；模板清单✓（已沉淀出结构骨架与用语对照表）→ **构成候选**；
- **提案要点**：候选名"同类材料写作助手"；选址＝本地模板库够、无需外连；脱敏＝骨架通用化，具体单位与人名不入模板；
- **边界写法**：只覆盖"有既有模板可循的重复起草"，一次性专稿不属本候选。

## 示例二 · 文件批量处理类

用户先为对象 A 手工做了一次"下载→转码→分册→建索引"的语料整理，轮到对象 B 时流程完全重复。

- **扫描**：场景重发✓（A、B 两个对象、同一流程）；步骤决策点✓（源格式判断→转换→切分→核验，每步有失败分支）；模板清单✓（转换脚本与核验清单已存在）→ **构成候选**；
- **提案要点**：候选名"批量入库工具"；把一次性脚本参数化（对象名/章节数/输出目录），第二个对象起一行命令完成；选址＝本地脚本够；
- **边界写法**：核心是"把已跑通一次的流程参数化"，不是"造一个通用批处理框架"。

## 示例三 · 已固化护栏被排除（演示第零筛）

用户反复问"装第三方技能前要不要审"，每次都要重讲一遍审计项。

- **第零筛**：审计项已写成纪律文件、且已有配套审计器在跑 → **护栏已固化，排除，不提案**；
- **换个角度才成立**：不重提"审什么"，而是提"装前决策树"（本地前提／联网范围／作者版本线），且必须写清与现成审计器的分工——**否则就是重造已固化的东西**。

## 反例（明确"不建议"）

用户让 AI 查了一次某政策文件的发布日期——无场景重发、无步骤决策点、无模板产出，三条全不中。**直接回答"不建议"，一句话说明理由即可，不展开分析。**

## 边界情形速查（这些一律不算候选）

| 情形 | 为什么不算 |
|---|---|
| 只做过一次的事 | 无场景重发 |
| 有想法但没做过 | 无实际发生过的任务可引证，不推测 |
| 步骤全靠临场发挥 | 无可描述的固定顺序与决策点 |
| 只有产物、没有可复用的模板或清单 | 三判据的第三条不中 |
| 护栏已固化（脚本在跑／纪律已成文） | 第零筛排除 |
| 市场已有现成同类技能 | 建议直接安装，不自建 |
| 纯一次性环境配置（装一次软件、改一次环境变量） | 不会重复发生 |
