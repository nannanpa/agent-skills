# 提案模板与样例（skill-miner 参考文件）

> 本文件是 SKILL.md 第 2 步的执行细则：模板（可复制）、一份**填写完成**的样例、字段校验清单、反例对照。
> 样例为虚构脱敏内容，不含任何真实机构、人名或内部数据。

---

## 一、一页纸提案模板（复制这段，逐行填）

```
## 候选技能：<名称>
- 状态：待裁 ／ 已建（技能名＋日期）／ 已否决（日期＋理由）／ 缓议（观察判据＋到期日）——四选一，必填
- 证据：本会话/记录中出现的任务（引用具体事项，1-3 条；标明是几个独立场合）
- 解决什么：一句话说清它替用户省掉什么重复劳动
- 覆盖范围：核心场景 1 句；边界外场景 1 句（诚实边界）
- 市场核查：目标技能市场／同类平台是否已有？有→写明差异；无→写"未命中"；没查→写"未查"。不许留空
- 选址结论：本地脚本够 / 需要外部连接 / 仅说明壳——为什么
- 敏感信息检查：需要脱敏的内容清单（人名/机构/内部数据）；确无时写"无（理由：…）"，不许只写一个"无"字
- 产物：<技能目录>/skills-candidates/<YYYY-MM-DD>-<主题>-提案.md（提案与技能同住；同日多份必须带主题名）
```

## 二、填写完成的样例（照这个颗粒度写）

> 以下为**虚构样例**，仅示范填写颗粒度与语气。

```
## 候选技能：内部简报起草助手
- 状态：待裁
- 证据：3 个独立场合——①某月为办公室起草月度简报时，先翻出上月旧稿对齐栏目与口径；②次月同一栏目顺序被打乱，
  又回头核对旧稿；③第三个月做年度合订，需从 12 份月报中还原固定栏目。
- 解决什么：省掉每次"先翻旧稿对齐栏目与口径"的动作，让起草从"找模板"直接开始。
- 覆盖范围：核心场景＝按既有栏目与口径起草周期性简报；边界外场景＝一次性专题材料（无既有栏目可依，不属本候选）。
- 市场核查：已查同类平台，有"周报生成器"类工具，但均面向数据自动成稿、不含"对齐本单位既有栏目与口径"这一步，
  差异即在本候选的起步动作。
- 选址结论：本地脚本够——栏目与口径都在既有文件里，模板本地化即可，不需要外连。
- 敏感信息检查：需脱敏=栏目名称中的内部机构简称、口径原文表述；本样例中已全部改为通用措辞。
- 产物：<技能目录>/skills-candidates/2026-10-30-内部简报起草助手-提案.md
```

**这个样例示范了四件事**：
1. 证据写清了**几个独立场合**（3 个），而不是"做过几次"；
2. 覆盖范围**写了边界外场景**（一次性专题材料不属本候选）——诚实的边界比漂亮的作用域有用；
3. 市场核查写了**差异点**，不是只写"没有"；
4. 敏感信息检查给了**具体清单**，不是一句"无"。

## 三、字段校验清单（产出前逐项核对，缺项必须占位）

| # | 字段 | 通过标准 |
|---|---|---|
| 1 | 状态 | 四选一，且写了日期／理由／判据（不是光写"待裁"以外的空壳） |
| 2 | 证据 | 1–3 条具体事项，标明独立场合数 |
| 3 | 解决什么 | 一句话讲清省掉了用户的哪一步重复劳动 |
| 4 | 覆盖范围 | 核心场景 1 句 + 边界外场景 1 句 |
| 5 | 市场核查 | 命中／未命中／未查，三选一，不许留空 |
| 6 | 选址结论 | 三选一 + 为什么 |
| 7 | 敏感信息检查 | 有清单写清单；确无写"无（理由：…）" |
| 8 | 产物 | 完整路径，含日期与主题名 |
| 9 | 技能目录来源 | 写明用的是用户指定路径还是探测第几条（见执行细则速查 §一） |

**任一项不合格**：用 `<待填>` 占位，并在文末列「待补字段：X、Y」。**不许静默漏项**——漏项的提案看起来完整，实际不可用。

## 四、反例对照（这些写法会让提案被判为不合格）

| 反例 | 问题 | 改成 |
|---|---|---|
| 「状态：」留空或写"已完成" | 四选一之外的值，下一轮无法判断该不该重提 | 「状态：待裁」 |
| 「证据：用户经常让我写材料」 | 无法核实的概括，且没写场合数 | 「证据：3 个独立场合——①…②…③…」 |
| 「市场核查：」留空 | 把选型判断整个推给用户 | 「市场核查：未命中」或写明差异点 |
| 「敏感信息检查：无」 | 一个"无"字看不出是否查过 | 「敏感信息检查：无（本提案不含人名、机构与内部数据，全部取自公开模板）」 |
| 「覆盖范围：什么都能做」 | 边界不明，等于没划边界 | 「核心场景…；边界外场景…」 |
| 同一目录同日写两份提案 | 落点撞名，后写覆盖先写 | 文件名加主题：`<YYYY-MM-DD>-<主题>-提案.md` |
