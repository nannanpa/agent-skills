# skill-miner（技能孵化器）

从你与 AI 助手的日常任务中，发现并提炼可复用的 Skill 候选。面向所有 Skill 机制宿主（Claude Code / Copilot CLI / OpenCode / WorkBuddy 等），平台中立。

## 它解决什么

非技术用户的流程经验、公文套路、排查手法沉淀在对话里，用完即弃；而"这能变成 skill"的判断门槛又太高。skill-miner 把这件事变成一句话："我让你帮我完成的任务里，能不能提炼 skill？"

## 流程

第 0–5 步，共六步：**圈定素材**（先读历史提案查重 → 读素材 → 按独立场合数重发 → 落素材清单以便断点续跑）→ **复盘扫描**（第零筛：护栏已固化先排除 → 三判据：场景重发＋步骤决策点＋模板清单）→ **候选提案**（一页纸 9 字段，只提案不建，批准权在用户）→ **批准后建档**（先过选址阀，再交给 skill-creator 规范建档并回填索引）→ **脱敏闸**（对外分享前逐项 grep）→ **收尾自查**（不留"待回流"，半成品续写不重开）。

开跑前先查重：读历史提案，列成"已建／已否决／缓议"三张名单，只提不在名单里的；名单状态识别不出的按"不可重提"处理。反复按**独立场合**数，不按文件数（同一目录下十个文件＝一次长往来）。

内置：偏差处置预案（八类症状的纠偏与恢复）、技术面异常统一错误格式 `[E1] 原因 → 我已做的 → 需要你做的`（错误码表 E1–E7 的逐条处置见 `references/执行细则速查.md`）、提案 9 字段校验清单、三类场景示例＋反例、常见问答。

## 安装

把 `skill-miner/` 目录（含 `references/`）放进你的宿主技能根目录即可（如 Claude Code `~/.claude/skills/`、WorkBuddy `~/.workbuddy/skills/`）。纯文档实现，零依赖，Windows/macOS/Linux 通用。

不支持技能目录、只能粘贴系统提示的环境：把 `SKILL.md` 全文粘贴为首段系统提示即可（正文含全部主干流程；错误码表、提案模板与样例在 `references/`，建议一并粘贴）。

## 文件清单

| 文件 | 用途 |
|---|---|
| `SKILL.md` | 执行主干：六步流程、提案 9 字段、偏差处置预案、常见问答、参考文件索引 |
| `references/执行细则速查.md` | 技能目录默认解析、提案目录与历史名单归一、素材格式识别、各宿主素材入口、技术面异常错误码表 |
| `references/提案模板与样例.md` | 可复制模板、一份填写完成的脱敏样例、9 字段校验清单、反例对照 |
| `references/场景示例.md` | 三类场景完整展开、一个反例、"这些一律不算候选"的情形清单 |
