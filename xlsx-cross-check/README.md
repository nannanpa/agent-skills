# xlsx-cross-check

多份 Excel 按指定键列做跨表匹配、逐键比对并出汇总表，强制"汇总数字与源表核对一致"才准交付——防漏加漏减。

> **作者**：和欣月　（经授权打包发行，2026-11-20 原样回传入库）

## 解决的问题

跨文件对齐同一批对象（团队/教师/项目）的同类数值、合并汇总，最容易出的事故是"汇总表算错/加漏了几个数没人发现"。本技能把"比对→汇总→核对"固化成一条链，核对门禁做**真实往返校验**（回读刚落盘的汇总文件再对源表），不一致即停并逐项报差异：

- **跨表按键匹配**：每个键命中哪些文件、同键异值差多少；
- **汇总核对门禁**：汇总数字与源表数字核对一致（浮点容差 1e-6）方可交付。

## 环境

Python 3 + openpyxl。安装依赖：

```
pip install -r requirements.txt
```

## 使用

```
python scripts/compare.py --files t1.xlsx t2.xlsx --key 团队 --value 论文数 --out summary.xlsx
# 退出码 0=核对一致可交付；1=不一致即停并报差异项
python scripts/make_samples.py   # 生成可复现样例源表
```
