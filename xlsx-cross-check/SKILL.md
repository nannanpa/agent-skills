# 跨表比对与汇总核对（xlsx-cross-check）

把“多份 Excel 按同一键对齐、合并汇总并确保没算错”这套动作固化。首版**只收两项**，其余进 v2 观察项。

## 首版范围（两项，其余不建）

1. **跨表按键匹配**：多份表按指定键（如“团队”“教师”“项目编号”）对齐，逐键比对——标出每个键命中了哪些文件、同键异值差多少。
2. **汇总核对**：比对后出汇总表（每键各文件值 + 合计 + 总合计），且**汇总数字必须与源表数字逐键核对一致**。

## 门禁（写死，不许改）

> **逐键核对（落盘每键合计 vs 源表每键求和，容差 1e-6）全部一致方可交付；任一键超差即停，删未通过产物并报真实两侧值——防逐键正负抵消穿透。**

## v2 观察项（本轮不进首版，各仅 1 例未达两次）

- 差异颜色标注（2026-05-11，C6EFCE／D9D9D9 双色）；
- 多评委排名计算与评分区间映射（2026-05-18，Excel 场景已核）。

## 工作流

```bash
# 0) 生成可复现样例源表（或用自己的表）
python scripts/make_samples.py
# 1) 跨表按键匹配 + 汇总核对
python scripts/compare.py --files samples/t1.xlsx samples/t2.xlsx \
       --key 团队 --value 论文数 --out samples/summary.xlsx
#   退出码 0=逐键核对一致可交付；1=输入错或不一致即停（并删未通过产物）
```

失败（输入重名，`EXIT=1`）：

```
[入参] 输入文件 basename 重名会互相覆盖：t1.xlsx（2 次）。完整路径：t1.xlsx -> /a/t1.xlsx；t1.xlsx -> /b/t1.xlsx。
怎么办：给文件改名使 basename 唯一后再跑。退出码 1.
```

## 入参

- `--files`：一份或多份 xlsx（首张工作表）。
- `--key`：对齐键列名（每份表须有，且同名）。
- `--value`：参与汇总/比对的数值列名（每份表须有，且同名）。
- `--out`：汇总表输出路径。

## 依赖

- Python 3 + `openpyxl`。宿主中立：不写死任何一家安装路径；脚本相对本技能目录定位样例。

## 反模式清单

| 反模式 | 后果 | 替代做法 |
|---|---|---|
| 传两份 basename 相同的文件（如 /a/t1.xlsx 与 /b/t1.xlsx） | 同名被当成同一来源同键相加，源表/汇总全错乱 | 报错退 1；给文件改名使 basename 唯一后再跑 |
| 同一张表内键列值重复 | 重复行被静默求和合并，掩盖数据质量问题 | 脚本打印警告列出重复键及次数；跑前先核对源表重复行 |
| 源表含合并单元格 | data_only 读回时合并区只有左上角有值，其余为空，可能漏数 | 跑前取消合并并逐格填值，或改用规范化明细表 |
| 键列含空值/空行 | 空键行被跳过，该行数值不进汇总 | 核对源表键列无空值；确为汇总行的用独立标记区分 |
| 只比总合计不逐键 | 逐键正负抵消可穿透门禁（多加一键、少写一键，总和仍相等） | 本版门禁已升级为逐键核对，勿回退为只比总额 |

## 常见问题（FAQ）

**Q1 汇总和源表差一点点（浮点尾差）算不一致吗？**
门禁按 `abs(差) < 1e-6` 判定，正常浮点尾差不会误拦；报"核对不一致"说明是真实差异（漏加/漏减/写错），会逐项列出来。

**Q2 各表的键列叫法不一样怎么办？**
`--key` 要求每份表列名完全相同；先统一源表列名再跑（本技能不改源表）。

**Q3 只想比对、不想出汇总表行吗？**
首版两项绑定：匹配比对＋汇总＋核对一次完成；拆分需求在 v2 观察项。

**Q4 文本列能汇总吗？**
不能。`--value` 必须是数值列；非数值列参与汇总属范围外。

**Q5 多 sheet 的表读哪个？**
只读首张工作表（入参节已声明）；指定 sheet 属 v2 观察项。

**Q6 源表会被修改吗？**
不会。比对只读源表（data_only 模式），唯一产物是 `--out` 指定的汇总文件。
