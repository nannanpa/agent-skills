# 跨表比对与汇总核对（xlsx-cross-check）

把“多份 Excel 按同一键对齐、合并汇总并确保没算错”这套动作固化。首版**只收两项**，其余进 v2 观察项。

## 首版范围（两项，其余不建）

1. **跨表按键匹配**：多份表按指定键（如“团队”“教师”“项目编号”）对齐，逐键比对——标出每个键命中了哪些文件、同键异值差多少。
2. **汇总核对**：比对后出汇总表（每键各文件值 + 合计 + 总合计），且**汇总数字必须与源表数字核对一致**。

## 门禁（写死，不许改）

> **汇总数字与源表核对一致方可交付；不一致即停并报差异项。**

## v2 观察项（本轮不进首版，各仅 1 例未达两次）

- 差异颜色标注（2026-05-11，C6EFCE／D9D9D9 双色）；
- 多评委排名计算与评分区间映射（2026-05-18，Excel 场景已核）。

## 工作流

```bash
# 0) 生成可复现样例源表（或用自己的表）
python scripts/make_samples.py
# 1) 跨表按键匹配 + 汇总核对
python scripts/compare.py --files samples/t1.xlsx samples/t2.xlsx \
       --key 团队 --value 论文数 --out samples/summary.xlsx
#   退出码 0=核对一致可交付；1=不一致即停并报差异项
```

## 入参

- `--files`：一份或多份 xlsx（首张工作表）。
- `--key`：对齐键列名（每份表须有，且同名）。
- `--value`：参与汇总/比对的数值列名（每份表须有，且同名）。
- `--out`：汇总表输出路径。

## 依赖

- Python 3 + `openpyxl`。宿主中立：不写死任何一家安装路径；脚本相对本技能目录定位样例。

## 常见问题（FAQ）

**Q1 汇总和源表差一点点（浮点尾差）算不一致吗？**
门禁按 `abs(差) < 1e-6` 判定，正常浮点尾差不会误拦；报"核对不一致"说明是真实差异（漏加/漏减/写错），会逐项列出来。

**Q2 各表的键列叫法不一样怎么办？**
`--key` 要求每份表列名完全相同；先统一源表列名再跑（本技能不改源表）。

**Q3 只想比对、不想出汇总表行吗？**
首版两项绑定：匹配比对＋汇总＋核对一次完成；拆分需求在 v2 观察项。

**Q4 文本列能汇总吗？**
不能。`--value` 必须是数值列；非数值列参与汇总属范围外。

**Q5 多 sheet 的表读哪个？**
只读首张工作表（入参节已声明）；指定 sheet 属 v2 观察项。

**Q6 源表会被修改吗？**
不会。比对只读源表（data_only 模式），唯一产物是 `--out` 指定的汇总文件。
