# 公文格式生成 + 读回自检（docx-format-guard）

把“按固定公文格式出 Word”这套重复动作固化成薄壳：**参数单 → 生成器 → 读回自检** 三层，缺一不可。

## 适用场景

用户反复要求“跟上次一样的公文格式”出 docx：A4、标题字体字号固定、正文仿宋、固定值行距、首行缩进二字符、国标页边距。本技能保证生成的 docx **真的**带上了这些格式，而不是只“跑通了脚本”。

## 三层结构（一个都不能少）

### ① 参数单（唯一取值来源）
- 文件：`scripts/params.json`（机器读）+ `references/参数单.md`（人读），两套并存：
  - **套 A（默认，成品口径）**：标题=方正小标宋_GBK 22pt 居中；正文=仿宋_GB2312 16pt；一级标题=黑体 16pt；首行缩进 2 字(=32pt)；行距=固定值 28 磅；页边距 上3.7/下3.5/左2.8/右2.6 cm（A4）。
  - **套 B（变体，用户明确指定才走）**：标题=黑体 22 号居中；行距=固定值 30 磅；页边距 上3.7/下3.5/左2.7/右2.7 cm。其余沿用套 A。
- **规则**：默认走套 A；仅当用户当次明确指定“黑体22号”时才走套 B。**技能不自行认文种、不按文件名猜。**
- **出处硬要求**：参数表里每一项都有 `source` 字段（机器读）或“出处”列（人读）；**不许出现无出处的数值**。套 B 标题出处抄有 `annual-report-case-selection` 第 6 条原文。

### ② 生成器（只从参数单读值）
- 脚本：`scripts/gen_gongwen.py`。
- **铁律**：只从 `params.json` 读值，**不写死任何字号/行距/边距**。改格式只改参数单，不改脚本。

### ③ 读回自检（生成后必须跑）
- 脚本：`scripts/selfcheck.py`：打开生成的 docx，**读回**并断言五项——字体／字号／行距／页边距／首行缩进。
- **读回断言＝不过就停**，不是自查表。

## 门禁（写死，不许改）

> **五项读回断言全过才允许交付；任一项不过即停并报“哪一项、实测多少、参数单写的多少”。**

## 三个坑（已写进自检，发行打包侧既有脚本反复踩过）

1. `line_spacing` 把 `Length` 当倍数 —— 固定值行距必须用 `Pt(值)` 且显式 `line_spacing_rule = WD_LINE_SPACING.EXACTLY`；单位写 **twips(磅)**，否则被当成行倍数。
2. 插入段落 **不继承样式** —— 必须对每个 run 显式 `set_run_font()` 设置 `run.font`（含 eastAsia），否则回读到的字体是默认字体而非指定字体。
3. 固定值行距的单位是 **磅**，不是“行” —— `line_spacing_rule` 必须是 `EXACTLY`，自检据此判 FAIL。

详见 `LESSONS.md`。

## 工作流

```bash
# 1) 生成（默认套 A；--set B 走变体）
python scripts/gen_gongwen.py --set A --out samples/sample_A.docx
# 2) 读回自检
python scripts/selfcheck.py --set A --docx samples/sample_A.docx
#   退出码 0=五项全过可交付；1=有未过项，即停并报明细
```

## 依赖

- Python 3 + `python-docx`（生成与读回均基于 docx 的 XML，不要求本机装有对应中文字体即可校验落盘值）。
- 宿主中立：不写死任何一家的安装路径；脚本相对本技能目录定位 `params.json`。

## 常见问题（FAQ）

**Q1 自检过了，但打开文档字体看起来不对？**
自检断言的是 docx 落盘 XML 里的值（字体名/字号/行距/边距），不校验本机是否安装了对应中文字体（方正小标宋_GBK 等）；宿主机缺字体时 WPS/Word 会替换显示。落盘值与渲染观感是两件事，本技能只保证前者。

**Q2 行距写了数字却变成"倍数行距"？**
固定值行距必须 `Pt(值)` 且显式 `line_spacing_rule = WD_LINE_SPACING.EXACTLY`——单位是磅不是行；漏 EXACTLY 会被当成行倍数（坑 1/坑 3，自检据此判 FAIL）。

**Q3 首行缩进"2 字"到底是多少？**
2 × 正文字号。16pt 正文＝32pt，不要写 0.74cm 这类近似值。

**Q4 什么时候走套 B？**
仅当用户当次明确指定"黑体 22 号"等套 B 特征；本技能不自行认文种、不按文件名猜，默认一律套 A。

**Q5 自检 FAIL 了怎么办？**
输出已报"哪一项、判据多少、实测多少"，对照参数单排查；自检只断言不修改，不会替你改文件。

**Q6 生成的新段落字体掉回默认？**
python-docx 插入段落不继承样式，必须对每个 run 显式设字体（含 eastAsia）；生成器已内置处理，自拼 XML 时极易踩。
