# docx-format-guard

按参数单生成中文公文格式 Word（.docx），并强制读回自检五项格式是否真实落盘——防止"看着生成成功、实际格式偏掉"。

> **作者**：和欣月　（经授权打包发行，2026-11-20 原样回传入库）

## 解决的问题

"每次都要跟上次一样的公文格式"是重复劳动，而 python-docx 生成 docx 有三个经典暗坑（行距单位、样式不继承、EXACTLY 规则），导致"脚本跑通了、格式没落上"。本技能把这件事固化成三层薄壳，缺一不可：

- **参数单**（唯一取值来源）：套 A（成品口径）／套 B（变体）双套并存，每项数值带出处，不许拍脑袋；
- **生成器**：只从参数单读值，不写死任何字号/行距/边距；
- **读回自检**：生成后自动打开成品逐项断言五项（字体/字号/行距/页边距/首行缩进），任一项不过即停并报"判据多少、实测多少"，不允许交付。

## 环境

Python 3 + python-docx。安装依赖：

```
pip install -r requirements.txt
```

## 使用

```
python scripts/gen_gongwen.py --set A --out 输出.docx     # 生成（默认套A；--set B 走变体）
python scripts/selfcheck.py --set A --docx 输出.docx      # 读回自检（退出码 0=可交付，1=即停报差异）
```
