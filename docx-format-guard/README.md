# docx-format-guard

按参数单生成中文公文格式 Word（.docx），并强制读回自检七项格式是否真实落盘——防止"看着生成成功、实际格式偏掉"。

> **作者**：和欣月　（经授权打包发行，2026-11-20 原样回传入库）

## 一句话原理

参数单（唯一取值来源）→ 生成器（只从参数单读值）→ 读回自检（生成后逐项断言，不过即停）。三层薄壳缺一不可。深度说明（三层结构、三个坑、FAQ、门禁细则）见 **SKILL.md**。

## 环境

Python 3 + python-docx：

```
pip install -r requirements.txt
```

## 使用

```
python scripts/gen_gongwen.py --set A --out 输出.docx     # 生成（默认套A；--set B 走变体）
python scripts/selfcheck.py --set A --docx 输出.docx      # 读回自检（七项：字体/字号/行距/页边距/首行缩进/页面尺寸/标题加粗）
#   退出码 0=七项全过可交付；1=有未过项或参数不一致，即停并报明细
```

自检启动会先比对 `params.json` 与 `references/参数单.md` 关键数值，不一致即停，防止双份维护漂移。
