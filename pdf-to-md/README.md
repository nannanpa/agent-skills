# pdf-to-md · PDF → 规整 Markdown（中文公文 OCR 产物专治）

> **版本 1.2.0**（2026-10-30）

把 PDF（尤其是 WPS/Adobe OCR 后带文字层的扫描件）转成段落连贯、结构清晰的 Markdown。三步管道：**①分流（有文字层？无则走 OCR）②提取／OCR ③规整**——去页码残留、合并强制断行、重排段首体系、拆分粘连的标题与字段标签、保护表格、打标噪声。附带 `diff_versions.py` 做两版逐段比对，便于人工核对改了什么。

> **定位**：不与 marker / docling / pymupdf4llm 比版面还原，只做 OCR 产物"从碎行到连贯段落"的最后一公里。规则清单专为中文公文结构设计，零依赖（仅 pypdf），全部规则可读可改。

（三）压实工作责任。各责任单位要对照          问题清单逐项整改销号，并将整改情况
问题清单逐项                                于每季度末报送领导小组办公室。

## 快速上手

```bash
pip install pypdf

# ① 提取文本层（先跑，看提取量）
python3 scripts/pdf_extract.py 输入.pdf 中间产物.md
#    每页有正常文字量 → 直接进 ③
#    每页几十字或为空 → 纯扫描件，走下面的 OCR 分支

# ② OCR 分支（仅纯扫描件；macOS 自带 PDFKit + Vision，零安装零网络零外部依赖）
swift scripts/pdf_ocr.swift 输入.pdf 中间产物.md          # PDF →渲染→OCR→带页标记，一条命令
swift scripts/pdf_ocr.swift 输入.pdf /tmp/o.md --page 3 --coords  # 疑难单行定位（置信度+坐标）

# ③ 规整
python3 scripts/clean_md.py 中间产物.md 最终.md "文档标题（提取文本·规整版）"

# ④ 规则改过之后，比对两版
python3 scripts/diff_versions.py 旧版.md 新版.md
```

**退出码**：`0` 成功 ／ `1` 参数错或文件错（都带「💡 怎么办」提示）／ `2` 输入里没有可规整的内容。

**可选开关**：`--para-patterns "正则|正则"`（追加自定义段首模式，不必改脚本）、`--no-punct`、`--no-noise`、`--no-redhead`。

规整后抽读头、中、尾各一段确认：无页码残留、段落连贯、标题独立成行、表格未被打散。

## 内置规整规则

| # | 规则 | 说明 |
|---|---|---|
| 1 | 页码残留清除 | `-3-`、`—15`、孤行数字整行匹配即删 |
| 2 | 强制断行合并 | PDF 逐行硬回车拼回完整段落，跨页断句靠页标记分块自然接上 |
| 3 | 段首识别重排 | `一、` `（一）` `1.` 节标题/条目体系 + `联系人` `责任单位` 等字段标签，强制另起段 |
| 4 | 标题粘连拆分 | `一、总体要求` 与前后正文断开；`（简称…）`不误断 |
| 5 | 字段标签断行 | 段中粘连的 `责任单位：` `联系人：` 前强制换行 |
| 6 | 节标题短行独立（v1.1.0） | OCR 层"一、××"式独立短行（编号+短标题、≤20 字无句读）直接成段——泛化判定不依赖词表 |
| 7 | 节标题粘连泛化拆分（v1.1.0） | 段中"句末标点＋编号、"即起段（标题起段、正文随段）；已知标题词仍做标题完整独立 |
| 8 | 标点归一化 | v1.1.0 两侧均 CJK 才转；**v1.2.0 收紧为任一侧邻接汉字或中文标点即转**（括号成对转换）——保护 `010-66097148`、`92-111`、`3.14`。**成对的英文直引号转中文引号**（`"…"` → `“…”`），奇数个时最后一个保持原样 |
| 9 | 噪声行打标 | 长串纯数字行、无汉字短行行尾加"〔噪声待核〕"——打标不删，人工复核 |
| 10 | 表格整块保护（v1.2.0） | 连续 `|` 开头行视为一个不可拆单元，行间不留空行——此前 5 列表格会被并成一行 |
| 11 | 噪声行内打标（v1.2.0） | 噪声串夹在句中同样标记（如 `L1ti`、`61202611016`）；与整行规则互斥，同一串只带一个标记 |
| 12 | 红头报头区扩展包（v1.2.0） | 发文机关标志／发文字号／标题／受文机关／落款日期／抄送拆成独立段 |
| 13 | 报头区三段分离（v1.2.0） | 标题与受文机关断开、受文机关与正文断开；冒号后是数字（`咨询电话:010-…`）则不动 |
| 14 | 版本比对（v1.2.0） | `diff_versions.py` 逐段对齐两版，输出新增/删除/改写三类差异 |
| 15 | 图片 PDF 全链路（v1.2.0） | `pdf_ocr.swift` 一条命令：PDF → PDFKit 渲染 → Vision 离线 OCR → 带页标记的中间产物，**零外部依赖**（不需要 PyMuPDF/pypdf）；低置信度行标〔OCR待核〕，传真页眉/页脚标〔页眉页脚〕（几何判据：行中心在页顶/页底 7% 且多页重复） |

**扩展**：改 `scripts/clean_md.py` 的 `PARA`（段首模式）与字段标签列表即可加新规则——通用公文骨架已内置，定制词按文档类型增删；不改脚本则用 `--para-patterns` 追加。

## 何时不用

- 需要保留表格线/图片/版式 → 本技能只产纯文本流（Markdown 表格保留行列内容，不还原边框）
- 非 macOS 的扫描件 → 自带 OCR 脚本是 Swift 版；其他系统请用本机 OCR 引擎，并保证输出仍是逐行文本
- OCR 错别字**不自动改**，只列可疑词清单人工核对，避免误改正文
