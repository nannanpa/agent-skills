# pdf-to-md · PDF → 规整 Markdown（中文公文 OCR 产物专治）

> **版本 1.1.0**（2026-10-19）

把 PDF（尤其是 WPS/Adobe OCR 后带文字层的扫描件）转成段落连贯、结构清晰的 Markdown。两步管道：**①提取文本层 ②规则化规整**——去页码残留、合并强制断行、重排段首体系、拆分粘连的字段标签。

> **定位**：不与 marker / docling / pymupdf4llm 比版面还原，只做 OCR 产物"从碎行到连贯段落"的最后一公里。规则清单专为中文公文结构设计，零依赖（仅 pypdf），全部规则可读可改。

```text
办公室。联系人：办公室　责任单位：各系部       责任单位：各系部
```

页码清零 ✅ 断行合并 ✅ 字段标签独立成行 ✅

## 快速上手

```bash
pip install pypdf
# ① 提取文本层
python3 scripts/pdf_extract.py 输入.pdf 中间产物.md
# ② 规整
python3 scripts/clean_md.py 中间产物.md 最终.md "文档标题（提取文本·规整版）"
```

规整后抽读头、中、尾各一段确认：无页码残留、段落连贯、标题独立成行。

## 内置规整规则

| # | 规则 | 说明 |
|---|---|---|
| 1 | 页码残留清除 | `-3-`、`—15`、孤行数字整行匹配即删 |
| 2 | 强制断行合并 | PDF 逐行硬回车拼回完整段落，跨页断句靠页标记分块自然接上 |
| 3 | 段首识别重排 | `一、` `（一）` `1.` 节标题/条目体系 + `联系人` `责任单位` 等字段标签，强制另起段 |
| 4 | 标题粘连拆分 | `一、总体要求` 与前后正文断开；`（简称…）`不误断 |
| 5 | 字段标签断行 | 段中粘连的 `责任单位：` `联系人：` 前强制换行 |
| 6 | 节标题短行独立（v1.1.0） | OCR 层"一、××"式独立短行（编号+短标题、≤20 字无句读）直接成段——泛化判定不依赖词表 |
| 7 | 节标题粘连泛化拆分（v1.1.0） | 段中"句末标点＋编号、"即起段（标题起段、正文随段）；已知标题词仍做标题完整独立 |
| 8 | 标点归一化（v1.1.0） | 半角句读两侧均 CJK 才转全角——保护 `010-66097148`、`2025—2027` 类数字串；括号成对转换 |
| 9 | 噪声行打标（v1.1.0） | 长串纯数字行、无汉字短行行尾加"〔噪声待核〕"——打标不删，人工复核 |

**扩展**：改 `scripts/clean_md.py` 的 `PARA`（段首模式）与字段标签列表即可加新规则——通用公文骨架已内置，定制词按文档类型增删。

## 何时不用

- 纯图像扫描件（无文字层）→ 第 1 步提取量为空，改走视觉识别（渲染成图逐页转写）
- 需要保留表格线/图片/版式 → 本技能只产纯文本流
- OCR 错别字**不自动改**，只列可疑词清单人工核对，避免误改正文
