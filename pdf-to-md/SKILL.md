# pdf-to-md：PDF → 规整 Markdown

专治**中文公文/红头文件类 PDF 的 OCR 产物**：提取文字层后，把碎行、页码残留、粘连的标题与字段标签规整成段落连贯的 Markdown。

> **定位**：marker、docling、pymupdf4llm 等重型工具比的是版面还原能力；本技能不跟它们比——只做 OCR 产物"从碎行到连贯段落"的最后一公里，规则清单专为中文公文结构设计（`一、` `（一）` `1.` 段首体系、"责任单位：/联系人："字段标签），并保持零依赖（仅 pypdf）、全规则可读可改。

## 何时用 / 何时不用

- ✅ PDF 带文字层（OCR 产物、原生电子 PDF）。不确定就先跑第 1 步，看提取量。
- ❌ 纯图像扫描件（无文字层）——第 1 步会提取出空文本，此时改用视觉识别（把 PDF 页渲染成图后逐页读图转写），不要硬跑本 skill。
- ❌ 需要保留表格线、图片、版式——本 skill 只产纯文本流。

## 管道（两步，顺序执行）

依赖：Python 3.8+ 和 `pypdf`。**安装 pypdf 请装进隔离虚拟环境，不要全局安装**（避免污染系统环境）：

```bash
python3 -m venv .venv && .venv/bin/pip install pypdf   # 或使用平台托管 venv（如已装 pypdf 则直接用）
.venv/bin/python <本skill目录>/scripts/pdf_extract.py 输入.pdf 中间产物.md
```

### 第 1 步：提取文本层

```bash
python3 <本skill目录>/scripts/pdf_extract.py 输入.pdf 中间产物.md
```

逐页提取，页间插 `<!-- 第 N 页 -->` 页标记（第 2 步靠它分块）。提取量异常少（如每页几十字符）说明无文字层，停下改走视觉识别。

### 第 2 步：规整

```bash
python3 <本skill目录>/scripts/clean_md.py 中间产物.md 最终文件.md "文档标题（提取文本·规整版）"
```

## 安装自检（装完先跑这一步）

安装后确认本目录下 **三个文件齐全**：`SKILL.md`、`scripts/pdf_extract.py`、`scripts/clean_md.py`。

- 若 `scripts/` 缺失（部分安装方式只抓取了 SKILL.md），先回 https://github.com/nannanpa/agent-skills 的 `pdf-to-md/scripts/` 目录补齐两个脚本，再使用；
- 实在拿不到脚本时，可按下方"规整规则清单"自行重建（两个脚本均为纯标准库+pypdf 的无状态实现，重建成本低），但**重建后须用"效果示例"做回归**：输入规整前样例，输出应与规整后样例逐字一致。

## 规整规则清单（clean_md.py 已内置）

按实战迭代出的规则，遇到新形态文档可往里补：

1. **页码残留清除**：`-3-`、`—15`、孤行数字等整行匹配即删
2. **强制断行合并**：PDF 每行末尾的硬回车拼接成完整段落（跨页断句靠页标记分块后自然接上）
3. **段首识别重排**：以下模式开头的行强制另起一段——
   - 节标题：`一、` `二、` …
   - 条目：`（一）` `(二)`（半角全角都认）`1.` `1、`
   - 字段标签：`联系人` `责任单位` `整顿重点` `查处重点` `组长/副组长/组员` `附件` `送：` 等
4. **标题粘连拆分**：`一、总体要求`等节标题与前后正文断开；`（简称…）`不误断
5. **字段标签断行**：段中粘连的`责任单位：``联系人：`等标签前强制换行

**扩展方法**：改 `clean_md.py` 里的 `PARA`（段首模式）和字段标签列表，加新关键词即可。通用公文骨架已覆盖，定制词（如"部内发送""工作提示"）按文档类型增删。

## 输出约定

- 最终文件名建议：`原文件名.md` 或 `原文件名（提取文本·规整版）.md`，放原 PDF 同目录
- 规整后必须**抽读头、中、尾各一段**确认：无页码残留、段落连贯、标题独立成行
- OCR 错别字（如"领城/问瓶"）**不要自动改**——只列可疑词清单交用户核对，避免误改正文

## 已验证案例

多份真实公文扫描件实测——页码清零、段落完整、清单一条一行。

## 已知边界

- **红头文件报头区会被合并成一段**：发文机关标志、发文字号、标题、受文机关、落款、日期这些行大多不带段首模式（如`连发〔2026〕X号``大连民族大学文件`），纯文本流下会与相邻行粘连。这是设计取舍——报头词因校而异，写死规则反而误伤；需要拆分时向 `PARA` 补本校的模式即可。
- **跨栏/双栏排版**的 PDF 提取后行序可能交错，本 skill 不做栏序还原，规整前请先目检第 1 步产物。
- **OCR 错别字不自动改**（见"输出约定"），规整版可能残留"领城/问瓶"类错误。
