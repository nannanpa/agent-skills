# 字段名表（本轮已遇到，保留原名）

> 用途：加新维度时**先查这张表**——名字与口径要和前几轮一致，否则同一件事两处叫两个名，下次又得重认。
> 出处：2026-10～11 同构材料四轮（合并稿／清单核对／分篇改稿／复核轮）。

| 字段名 | 定义 | 判据／口径 | 出处 |
|---|---|---|---|
| **段数** | 非空段落数（`doc.paragraphs`） | 与上一版比，增减要有逐项账 | 复核清单、核对规程 §一 |
| **字数（去空白）** | 全部段落拼接后去 `\s` 的长度 | **全程同一口径**；换口径＝换结论 | 核对规程 §一 |
| **序号** | 段首 `1.` / `1、` / `1．` 的编号 | 同一列表内严格 +1；允许从 1 重启 | 复核清单（01 篇 16→19 缺 18） |
| **目标条** | 以 `——` 起头的一句话指标/目标 | 同构集应 17/17 统一为 `——` | 复核清单§二 |
| **目标条（异常体）** | `1.` / `（1）` / 小标题体写目标 | 出现即该篇未归一 | 复核清单§二表 |
| **篇幅** | 该篇字数（去空白） | 报中位＋极差；超中位 1.3 倍单独看 | `00-篇幅提示汇总.md` |
| **篇内重复指标** | 同篇同一数值 ≥2 次 | 多为"目标写一遍、举措再写一遍" | 复核清单（14 篇 600 万、20 万） |
| **跨篇金额类** | 万/亿/元数值，≥3 篇出现 | 线索，非结论 | 本轮脚本新增 |
| **批注** | 只提出、不改正文的意见 | 属"须单位定"的项（口号、口径、拆节） | 复核清单（10 篇"请单位删"） |
| **修订** | 真改正文并留痕 | 属"必改"的项（序号、错字、人名字段） | 复核清单（06 篇两处人名） |
| **红线词** | 项目自带禁用词表 | 逐个 `count` 为 0 | 核对规程 §六 |
| **修订痕迹** | `w:ins`/`w:del` 计数 | 交印前必须 0 | 核对规程 §五 |
