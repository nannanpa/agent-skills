# 例 03 · 含表格与"小标题体"：脚本核不到什么、人工补看什么（合成样本，可复现）

> 真实运行：2026-11-17，python-docx 合成一篇含 2×2 表格的材料：正文编号 1./2.（"1. 体"），
> 表格单元格内另有序号 3.、5.（与正文不衔接）。全部数字为实跑原值。
> 本例专答评测与用户都关心的问题：**哪些地方脚本天生核不到，人工要补看什么。**

## 一、材料结构（合成）

```
××学院发展规划            ← 正文段
一、主要目标              ← 小标题（"一、"体，6 字）
1. 到2030年建成3个重点学科   ← 1. 体（该用"——"体）
2. 完成15项改革任务
[表格] 任务 | 负责部门
       3. 建设实验室 | …
       5. 引进人才 | …     ← 表内序号 3、5：与正文 2 不衔接，且 3→5 跳号
```

## 二、实跑输出与逐行解读

```bash
python3 "$SKILL_DIR/scripts/hecha.py" doc 含表格样例.docx
```

```
文件                             段     字数   序号项   目标条   问题
含表格样例.docx                     4     41     2     0    0
```

**问题数 0、目标条 0——但这份材料有两处真问题，脚本都没报**：

| 脚本没报什么 | 为什么（机制层） | 人工补看口径 |
|---|---|---|
| 表内序号 3→5 跳号、且与正文 2 不衔接 | `doc.paragraphs` **不含表格单元格文本**——表体编号根本不进扫描流（"序号项 2"只是正文两条） | **表内编号逐个手核**：与正文编号衔接、表内自身连续；表越多越要核 |
| 正文 1. 体未用"——"体（D2 未报） | D2 靠关键词：须有含"目标/指标"且 **≥10 字符**的非标题段；本例"一、主要目标"6 字且被识别为小标题，不计入 → 关键词计数 0，判据不触发 | **看篇首有无"目标/指标"类小节**：有且正文用 1./（1）/小标题体 → 该篇未归一，人工点名 |

## 三、本例演示的已知局限（§六第 2、1 条的活例）

1. **表格内序号不解析**——判据建立在"顺序可靠的段落文本流"上，表格是另一套结构，v1.0.0 起如实登记、不静默装作核过。
2. **D2 靠关键词**——完全不用"目标"字样、或关键词只在短小标题里的篇会漏判（首轮 17 篇实测 7 篇该归一命中 6 篇，同一机理）。改进方向（D2 第二信号）已列 §七待补第 6 条，须实测防误报后再动。

**结论**：脚本报 0 ≠ 材料没问题。同构批核的正确用法是**脚本扫横向四维 ＋ 人工按上表补看表格与小标题体**，两层加起来才闭环。
