## 模块 0 · 关系档案结构化（存储层）

主文件的「关系档案维护」讲了原则，这里给**可执行的结构**。

### 0.1 单条目格式

```
[日期] [类型] 内容
类型 ∈ 事件（发生的）/ 判读（读出的）/ 基准线（TA 的常态）/ 快照（阶段小结）
```

每条事件必须带：**说话人标注**、原话或行为描述、在场情境（一句话）。
每条判读必须带：**置信度**、依据是记录原文还是补述。

### 0.2 阶段快照（供模块 A 轨迹对比使用）

每 2–4 周（或每个明显阶段结束时）出一份快照：

```
[快照 YYYY-MM-DD～YYYY-MM-DD]
六维评分：通道深度 / 双向耦合 / 信号稳定性 / 排他迹象 / 日常渗透 / 空间信号（各 0–5，见模块 B）
本期关键事实：3 条以内（记录原文级别的）
本期不可判定项：列出
数据量：本期归档条数
```

⛔ **快照必须当场生成，禁止回头补写。**补写的快照是记忆的自我叙事化，不是数据。漏了就漏了，下一期照常出。

### 0.3 存储纪律

- 档案是**校准工具，不是证据库**：允许留白，不做追溯考据。
- 推断永远停留在「判读」类型里，**永不升级为事件**——哪怕后来被证实，也只追加一条新事件（"后续证实"），原判读不改。
- 一段关系一个档案文件；换关系必须另起炉灶、重新立基准线。

## 模块 A · 关系轨迹对比（多期横向分析）

**触发**：用户给出 ≥2 期档案快照 / 两次独立分析结果，问"关系有没有变化""走向如何"。

### A.1 流程

1. 对齐期数：各期的时间范围、数据量。**数据量悬殊的期不可直接对比**（30 条对 5 条，评分差异可能只是采样密度差异）——先声明，必要时按条数归一。
2. 逐维对比（用模块 B 的六维量表）：每维标 **升 / 降 / 稳 / 不可判定**，变化幅度（±1 为微、±2 以上为显）。
3. 每个变化**回指证据**：变化由哪几条记录支持，列出条目日期。
4. 输出轨迹叙述：按"什么变了 / 什么没变 / 变化的证据 / 什么还看不出来"四段。

### A.2 轨迹纪律（防把噪声当趋势）

- **≥3 个数据点才谈"趋势"**。两点之间只能谈"变化"（升了/降了），不能谈"走势"（在变好/在变坏）。走势需要方向持续 ≥3 期。
- **单期波动先查情境**：节日、生病、工作高压、旅行——这些都能造成整期偏离。有情境的期须标注，趋势计算时降权。
- **轨迹叙述禁止编因果**。"她撤推荐之后关系降温了"——只有先后，没有因果。规范句式："X 发生在前，Y 随后变化；是否相关，证据不足。"
- **别把基准线漂移当关系变化**： TA 的常态本身会随季节、工作周期变。每期对比先校基准线是否也变了。
- 变化幅度 ±1 以内且无新类型证据 → 判"稳"，不要描写成"微妙的变化"。

### A.3 输出

轨迹叙述 + 变化表（维度 | 上期 | 本期 | 变化 | 证据条目 | 置信度）。**叙述按内容组织，不按维度逐条念**——读者要听"这段关系这一个月的走向"，不是听你念表。

## 模块 B · 情感雷达图

**触发**：用户要求"雷达图 / 可视化 / 直观看现状"。**使用门槛：≥2 周记录、≥20 条归档**。不足时明确拒绝并说明："数据还撑不起一张图，画出来是错觉的形状。"这句话本身就是合格输出。

### B.1 六维量表（0–5 分，每分须有证据条数支撑）

| 维度 | 0 分 | 5 分 |
|---|---|---|
| 通道深度 | 仅公域互动 | 稳定的私聊通道，可容纳非事务内容 |
| 双向耦合 | 单向发起（一方总在伸手） | 双向发起大体均衡 |
| 信号稳定性 | 信号忽有忽无、无法重复 | 同类信号跨时间可重复 ≥3 次 |
| 排他迹象 | 该行为人人可得 | 多点排他迹象（专属称呼、仅给你的信息、绕过群体的安排）|
| 日常渗透 | 只在特定场合出现 | 渗透到日常琐事（天气、吃饭、随手分享）|
| 空间信号 | 无主动接近 | 持续的空间接近与在场（提前到、绕路、留场）|

### B.2 评分规则

- 每维给分 + **一句依据**（引用条目数：如"依据 3/12、3/27、4/02 三条"）。
- **证据不足的维度不打 0 分，标"数据不足"**——图上画空心/虚线。0 分是"有证据表明很低"，数据不足是"不知道"。两者必须区分。
- 排他迹象是**默认低分维度**：排他最难证（需要对"TA 对别人"的观测），没有对照数据就不超过 2 分。
- 图必须标注：数据时间范围、归档条数、生成日期。
- **雷达图是快照，不是预测**。图旁禁止出现任何趋势语言（"照这个趋势…"）。

### B.3 输出

- SVG 六边形雷达（六轴、标分数、数据不足的轴用虚线）。生成 SVG 时：深浅主题自适应用中性色，多边形填充半透明，轴标签用维度中文名。
- 无渲染条件时降级为 Markdown 表：维度 | 得分 | 数据状态 | 一句依据。

## 模块 C · 语气语调指纹

**目的**：区分「风格变化」与「态度变化」。人在换设备、换心情、忙的时候打字习惯会变——**没有这个模块，风格漂移会被误读成冷淡**。

### C.1 基线建立（≥30 条历史消息）

提取五个指纹项：

1. 句长分布（短句党 / 长句党）
2. 标点习惯（感叹号频率、省略号、波浪号）
3. 表情与语气词（频率、类型、位置）
4. 称呼方式（对用户的固定称呼、有无变化）
5. 长度比（TA 的回复长度 ÷ 你的消息长度，取中位数）

基线写进档案（类型=基准线），**每 2–3 个月刷新一次**——人会变，基线也会漂。

### C.2 偏离检测

新消息在 ≥2 个指纹项上明显偏离基线时：

1. **先列情境解释**（至少两个）：最近忙什么、有没有换设备、说话场合（群里/私聊）。
2. 情境解释能覆盖 → 记"风格波动"，不入判读。
3. 覆盖不了 → 才进入态度分析，且**单次偏离置信度封顶"低"**；连续 ≥3 次、多维度、跨 ≥2 周的偏离，才可升"中"。

### C.3 纪律

- **风格偏离单独不构成态度信号**——它是待解释项，不是证据。
- 指纹是统计描述，不是人格判断。禁止从指纹跳到"TA 是个什么样的人"。

## 模块 D · 多人关系网络（简版）

**触发**：材料里出现 ≥3 人的稳定互动（群聊、共同场合）。

### D.1 记录单元

- **节点**：人（用代号）。只记材料里实际出现的人。
- **边**：两人之间的互动性质——同盟（互相支持）/ 张力（摩擦记录）/ 通道（信息常经此人）/ 闸门（此人控制信息是否流动）。边按行为记，不按猜测记。
- **通路**：一条信息实际走过的路径（谁知道、经过谁、到谁为止）。

### D.2 分析问题（只回答这三个）

1. **我在网中的位置**：中心（多条边汇聚）/ 边缘 / 桥（唯一连接两群人的通路）。桥位有特殊负担：两边的情绪都会经过你。
2. **信息通路与闸门**：什么信息流向谁、在哪里被闸住。闸门位置的人拥有不显眼的权力。
3. **三角动力学**：A–B 亲密时 C 的行为、A–C 亲近时 B 的行为——只记录观察到的，不预测。

### D.3 纪律

- **阵营思维禁令**：不得输出"敌我结构""谁站谁"。网络图描述通路，不描述立场。
- **单人视角声明**：网络图是**你看到的**网络，不是全貌。你看不到的边可能比看到的多——每次输出网络分析都带这一句。
- 边的性质须 ≥3 次行为支撑；一次摩擦不成"张力边"，一次帮忙不成"同盟边"。

## 模块 E · 性格类型参考（MBTI 等）——降级警示模块

**定位**：MBTI 及同类类型学（九型、DISC）的**科学信效度有限**。本模块的存在是为了**防止类型学污染分析**，不是为了用它。

### E.1 使用条件（全部满足才可提及）

1. 对方**自己说过**自己的类型（自述）；
2. 只作为**沟通偏好**的参考（如自述 F 型 → 表达可能偏感受措辞，分析时不把措辞硬度当冷漠）；
3. 提及必须带降级语："仅按 TA 自己的说法参考，不作为依据。"

### E.2 禁令

- ⛔ 禁止从聊天记录**反推** TA 的类型并作为分析依据。
- ⛔ 禁止"TA 是 XXX 型，所以 TA 会…"句式——类型学没有这种预测力。
- ⛔ 禁止用类型解释冲突（"你们俩类型不合"）——这是把结构问题宿命化。

### E.3 替代

想理解风格差异，用**模块 C（语气指纹）**：可测量、可证伪、可刷新。想理解价值观差异，回到行为证据。类型学给不了行为证据给不了的东西——它只是听起来像解释。
