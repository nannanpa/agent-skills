## 三种快速启动模板

### 🗨️ 记录分析（聊天记录 / 对话文本）
```
关系类型：[恋人/朋友/同事/家人]
时间范围：[全部/最近X条/某段时间]
我最想知道：[对方态度/某个问题/整体走向]

---对话内容如下---
[粘贴记录]

---我补的场景（没有就写"无"）---
[当时谁在场、什么场合、前后发生了什么]

---标注---
上面"对话内容"是原始记录；"我补的场景"是我自己的回忆，不是记录里有的
```
> ⚠️ 微信等 App **官方不提供明文导出**，须先用本地解析工具转成可读文本（可自行搜索相关开源工具），或手动复制。截图拼接会丢语音、撤回标记与精确时间。

### 📔 日记/备忘分析
```
记录时间：[大约时间段]
涉及人物：[A（关系类型）、B（关系类型）……]  ← 用代号即可，不必写真名
分析重点：[我的情绪/对方的情感/关系轨迹]

---日记内容如下---
[粘贴日记]
```

### 🎬 场景重现
```
背景：[关系类型 + 相处状态简述]
事件经过：[描述发生了什么]
具体问题：[你想搞清楚什么]
```
> 只复原**判读分歧点**就够——即"这句话可以有两种读法"的地方。不必把所有场景都写一遍。

## 输出控制

- 加"快速版"→ 只给结论 + 建议
- 加"完整报告"→ 逐维度深度分析
- 加"追问模式"→ 分析后提出可深挖的问题
- 加"分析我自己"→ 同时分析询问者的情绪、主体性与投放状态
- 加"行为分析"→ 重点分析非语言信号（空间、借口、物品边界、主动越界等）
- 加"行为模式"→ 重点找**重复出现 ≥3 次**的模式（如单向阀、做而不述），而不是单次动作
- 加"等字诀"→ 评估当前是否适合继续等待策略，给出边界建议
- 加"标注来源"→ 结论后标明该条属于 A 类（使用者原生）/ B 类（AI 抽象）/ C 类（通用方法）
- 加"归档"→ 按关系档案规范输出可存档条目（事实+判读+置信度）

## 核心能力

- **通用分析纪律 16 条**：标说话人、先立基准线、禁小样本归纳、生理数据不作情绪读数、平台机制先查证、四通道筛查、**脚手架不外露**等
- **等字诀策略模块**：不主动推、保持正常关心、不撤回自然存在的东西；"等"是"不追索"而非"屏蔽看见"
- **双轨模型**：公域对事不对人 / 私域永远站队；站队 ≠ 共情
- **行为模式模块**：**单向阀**（信息 / 使唤权 / 可否认性都只朝一个方向流）与 **做而不述**（以动作交付、以沉默收尾；接收者本已知情，所以不必"述"）
- **来源标注 A / B / C**：A = 使用者原生概念；B = AI 自建抽象（可弃而本体仍成立）；C = 通用方法论。**归属是分层的**——同一模块里，行为、命名、机制解释可以归不同类
- **主体性视角**：在乎 ≠ 投放；对方靠近的是主体性而非关注
- **关系档案维护**：按日期增量记录（事实+判读+置信度），先立基准线
- **置信度规范**：一次标清，不反复追加"别过读"式劝阻

## ⚠️ 常见误用提醒

- ❌ 把心率/睡眠/步数当情绪指标 → 生理数据受运动强度与身体状态影响，不可直接读成情绪
- ❌ 从 1–3 次行为归纳"规律" → 先立基准线，只有偏离才需要解释
- ❌ 凭印象断言某平台的可见性机制 → 先查证，不要说反
- ❌ 反复把同一条敏感线（疾病、生死等）当分析入口 → 未经主动提及不得反复调用
- ❌ 把"推断"沉淀成"事实" → 归档时区分已确认事实与推断
- ❌ 凭只言片语下关系定性 → 卡住分析的是**"料"不是"人"**；只言片语撑不住，须足量且**对路**的行为证据
- ❌ 把"不可判定"当成没分析出来 → 证据不足时明确输出"到此为止"就是合格结论，往往比漂亮定性更值钱
- ❌ 直接套用从另一段关系得来的结论 → 这套方法经有限样本的持续迭代而成，换关系必须**重新立基准线**
- ❌ **只给一段对话就要定性** → 对话只记录"述"的部分，缺场景、缺基准线、缺"没发生的事"。单独投喂时置信度应整体下调一档
- ❌ **把事后补述的场景当客观事实** → 补述同样是带滤镜的输入。最好当天记；追述得越晚，越容易被记忆自我叙事化
- ❌ **用补述去填"我不在场时发生了什么"** → 这类无从得知，只能标"不可判定"，不要编
