### 新增

- **`config.json` 四参数模板**：`swap_warn_mb` / `wechat_max_procs` / `trash_aged_days` / `agent_browser_path`（回收站天数初版为两键，v1.0.1 起合为单键，见下节）。缺省、类型错、越界均回退单键预设，不中断流程。

### 判据与边界（本版三条硬约束）

1. **所有归属类判断均为本地证据、不构成授权依据**——路径能证明"谁启动的"，不能证明"此刻在做什么"。差额由用户补，不由技能猜。
2. **绝不按内存大小挑进程终止**：大小是资源指标、不是状态指标，按大小杀的排序结果恰是"优先杀状态最重的"，方向性错误。
3. **不可逆动作一律两段式**：回收站经归档区、删除前报路径与体积并经用户确认。
