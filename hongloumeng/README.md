# hongloumeng · 红楼梦全本语料技能

《红楼梦》（石头记）全本语料 + 导览技能：**程高本 120 回（简/繁双版）+ 脂砚斋重评石头记 80 回（含甲戌/己卯/庚辰等脂批约 3900 条）**，按回存文，供原文检索、引用与版本对读探究。

> **定位**：GitHub 上红楼梦全文并不稀奇（古腾堡计划、维基文库都有）；本技能卡进的是**整理质量**的空档——"skill 化 + 程高本/脂评本双版本对读 + 脂批按抄本类型结构化 + 四批可追溯校勘"的组合，目前没有第二个。不做内容概括替代原文：回答涉及文本的问题时，必须回到原文核对后再引用。

## 工作流

1. **定位回数**：查 `回目索引.md`（按回目关键词或人物+情节）
2. **读原文**：`Read` 对应章节文件；正文均为简体，Grep 直接用简体检索
3. **查批语**：脂本问题读脂评本分册，批语按【批语类型：内容】内嵌于正文
4. **引用规范**：注明版本 + 回目（如"程高本第三回"/"庚辰本第二十七回"）；两版本文字有异时说明所据版本
