# 红楼梦全文语料技能

本技能是**语料库 + 导览**：按回存全文，供原文检索、引用与探究。不做内容概括替代原文——回答涉及文本的问题时，**必须回到 references/ 中的原文核对后再引用**。

## 目录结构

```
references/
├── 程高本120回_简体/ch001.txt … ch120.txt   # 通行本全文（简体，检索用首选）
├── 程高本120回_繁体/ch001.txt … ch120.txt   # 繁体原样（PG 版，含少量旧式标点）
├── 脂评本80回_含脂批/ch000_戚蓼生序与甲戌本凡例.txt
│                     ch001.txt … ch080.txt   # 简体，批语以【】嵌于正文
├── 回目索引.md            # 两版本全部回目
├── 人物谱.md              # 主要人物、判词、家族关系速查
├── 人物索引.md            # 全量人物索引（224 人，分 15 组，含语料频次，经逐名回验）
├── 人物关系.json          # 结构化关系边数据（136 条：亲属/主仆/婚恋/恩怨），供程序化查询
├── 贾府世系图.html        # 交互式世系图（宁荣两支五代 + 四大家族联姻，点击看详情）
├── 诗词韵文索引.md        # 重要诗词曲赋 → 所在回速查
├── 批语索引.md            # 脂批结构化索引（4100+ 条：回数/位置/出处/原文/涉及人物，可 grep）
├── 脂批指南.md            # 脂批类型、著名批语、伏笔研究方法
└── 校勘记.md              # 已修复讹误清单 + 残留缺陷定位（引用前可查）
verify.py                  # 语料回归测试（python3 verify.py，改语料后必跑）
```

## 工作流

1. **定位回数**：先查 `回目索引.md`（按回目关键词或人物+情节判断），确定回数 N。
2. **读原文**：`Read` 对应章节文件。正文均为**简体**，Grep 检索直接用简体即可。
3. **查批语**：脂本问题（伏笔、佚稿线索、作者态度）→ 先 Grep `批语索引.md`（按批语关键词、人物名定位，命中行带回号/位置/出处），需要看上下文再读 `脂评本80回_含脂批/ch0NN.txt` 原文。
4. **人物问题**：查某人身份/关系 → `人物索引.md`（全量，含频次）；程序化关系查询 → `人物关系.json`；向用户展示世系/联姻 → `贾府世系图.html`；判词与结局 → `人物谱.md`。
5. **引用规范**：注明版本 + 回目（如"程高本第三回"/"庚辰本第二十七回"）。两版本文字有异的句子，引用时说明所据版本。

## 检索陷阱（2026-10-12 第四批修复后更新）

1. ~~底本残留 mojibake~~：**已全部清零**（第四批修复 72 处，含「玉在椟中求善价」「静极思动」），按正确写法检索即可。
2. **生僻字 Ext-B 变体**：简体版有 11 个生僻字以扩展 B 区字形存储，常规字形搜不到。实测分布：ch027/042 𤇭（炊）、ch028 𣬠𣬶、ch030 鸂**𫛶**（鶒）、ch041 **𤫫**瓟斝、ch050 **𫘧**駬（騄駬）、ch064 𠺕、ch078 **𫉁**/**𫛛**/**𬙋**、ch094 **𬯎**（颓）。→ 改搜繁体版或该字的邻近词。
3. **回目标题格式**：标题为「第一二零回」式逐位数字（非「第一百二十回」）；定位回数以文件名 `chNNN` 为准，勿按标题字样猜。
4. **脂批泐损 □**：脂本 56 个 □ 系原件缺损（校勘记第四节逐条注明），检索命中 □ 属正常现象，勿当乱码报错。
5. **同回目不同文**：脂本 ch067（他本配补）回目作「见土仪颦卿思故里 闻秘事凤姐讯家童」，与程本「冷郎君惧祸走他乡」不同——按回目检索两版本要各试各的措辞。
6. **句号风格**：程高本正文用「．」作句号（PG 原档风格），含句号的检索串注意兼容「．/。」两种写法。

## 两版本要点

- **程高本 120 回**：前 80 回经程伟元、高鹗整理，后 40 回为续书。适合查通行情节（如黛玉之死、宝钗成婚的完整结局）。
- **脂评本 80 回**（甲戌/己卯/庚辰合成，64、67 回以他本配补）：保存曹雪芹原貌片段与脂批。**后 40 回无脂本**，涉及 81—120 回只能用程高本。
- 回目文字与分回略有出入（如程本"游幻境指迷十二钗"vs 脂本"开生面梦演红楼梦"），见 `回目索引.md`。

## 脂批格式

批语类型：【甲戌侧批】【甲戌眉批】【甲夹批】【庚辰双行夹批】【庚辰侧批】【蒙侧批】【蒙回前总评】【蒙回后总评】等。凡例与回前回后总批单独成段。检索批语优先用 `批语索引.md`（Grep 批语关键词或人物名）；直接读脂本原文时可 Grep `【甲戌`、`【庚辰双行` 等前缀。

## 语料维护

任何对 references/ 语料的修改之后，必须运行 `python3 verify.py` 回归测试（完整性、□、mojibake、引号、18 个关键引文点、简繁一致、ch055、脂本 □ 基线九项检查），全部 PASS 且在校勘记备案后方可定稿。

## 引文注意事项

- 正文按网络转录本整理，已修正若干处明显讹误；**严格校勘场景**（论文引据）建议核对影印本。
- 程高本繁体版保留 Gutenberg 原始排版痕迹（旧式标点、个别异体字），引用以简体版为准，繁体版仅供字词考订。
- 后 40 回非曹雪芹原稿，讨论"作者本意"时须区分前 80 回证据（含脂批）与续书内容。
