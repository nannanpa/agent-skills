# 脂批指南

脂砚斋（及畸笏叟等）批语是探佚《红楼梦》原稿意图的第一手材料。本库批语以【】内嵌于正文，前缀标明类型。

## 批语类型与格式

| 格式 | 含义 |
|---|---|
| 【甲戌侧批：…】【甲戌眉批：…】【甲夹批：…】 | 甲戌本批语（存 1-8、13-16、25-28 回等） |
| 【庚辰侧批：…】【庚辰双行夹批：…】【庚辰眉批：…】 | 庚辰本批语（主体） |
| 【己卯侧批：…】 | 己卯本批语 |
| 【蒙侧批：…】【蒙回前总批：…】【蒙回后总批：…】 | 蒙古王府本 |
| 【戚序…】/戚本 | 戚蓼生序本（本库 64/67 回配补主要来源之一） |
| 【靖藏…】 | 靖应鹍藏本（本库个别辑录） |

检索建议：Grep `【甲戌` / `【庚辰双行` / `【蒙回后总评` 等前缀；查某人伏笔可 Grep 人名+"一干人"（如 `贾赦、雨村一干人`）。

## 著名批语速查

- **全书总纲**：1 回"美中不足，好事多磨……究竟是到头一梦，万境归空"句旁批："四句乃一部之总纲"（另见 5 回曲文批）。
- **作者自白**：1 回"满纸荒唐言"诗旁批；"字字看来皆是血，十年辛苦不寻常"（甲戌凡例末）。
- **秦可卿旧稿**：13 回眉批："秦可卿淫丧天香楼，作者用史笔也……因命芹溪删去'遗簪''更衣'诸文。"——判词"情天情海"探佚核心。
- **草蛇灰线**：第 1 回批"草蛇灰线，伏脉千里"；19 回批"一树千枝，一源万派，无意随手，伏脉千里"。
- **钗黛合一**：42 回回前批："钗玉名虽两个，人却一身，此幻笔也。"
- **袭晴对映**：8 回批"袭乃钗副，晴又黛副"（通行概括；5 回判词批"骂死宝玉，却是自悔"）。
- **佚稿线索（30 回后原稿）**：
  - 31 回回目"因麒麟伏白首双星"——湘云婚事伏笔。
  - 20 回批"袭人出嫁之后，云丫头未免免不了'花花公子'（按原文作'好歹留着麝月'）"提示宝玉身边人散场次序。
  - 42 回批"刘姥姥之憨从利，凤姐之利从憨，写来恰成一对"及巧姐与刘姥姥结缘伏笔。
  - 79 回批提示迎春婚后、薛蟠娶夏金桂之后文字为原稿近尾。
- **"树下人"与怡红夜宴**：63 回"群芳夜宴"签语（宝钗牡丹、黛玉芙蓉、探春杏花、湘云海棠等）为判判词之副线。
- **眉批纪年**：庚辰本多署"壬午春/壬午季春·畸笏""丁亥春·畸笏叟"，是考证批书人存殁与成书过程的关键。

## 用批语做探究的方法

1. **以批证文**：遇到情节突转，先 Grep 该回内批语（如 13 回秦氏之死、25 回魇魔法）。
2. **以批探佚**：判词、曲文、灯谜、戏文处批语密度最高（5、22、63 回），是推想 80 回后情节的主要依据；务必区分"批语明示"与"后人推测"。
3. **注意批语矛盾**：甲戌、庚辰批语非一人一时，畸笏叟与脂砚斋身份学界有争议；引用时注明所据批语类型与回目。
4. **版本局限**：本库为合成整理本（庚辰为主体，缺回以他本配补），批语归属以【】前缀为准，未含影印本全部异文。
