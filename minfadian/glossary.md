# 术语表（按拼音首字笔画归组，指向条文）

## 主体类

- **自然人 / 法人 / 非法人组织** — 三类民事主体（第13条、第57条、第102条）
- **营利法人 / 非营利法人 / 特别法人** — 法人三分法，机关法人、事业单位属特别法人（第76/87/96条）
- **法定代表人** — 依法律或章程代表法人从事民事活动的负责人，职务行为后果由法人承担（第61条）
- **职务代理** — 执行法人工作任务的人员就职权范围内事项以法人名义实施的行为，对法人发生效力（第170条）
- **监护** — 未成年人以父母为当然监护人；成年监护尊重被监护人真实意愿，"最有利于被监护人"原则（第26—39条）
- **个体工商户 / 农村承包经营户** — 自然人从事经营的特殊形态（第54—56条）
- **宣告失踪 / 宣告死亡** — 下落不明满2年/满4年（或意外事件满2年）可申请（第40/46条）

## 物权类

- **物权** — 权利人依法对特定的物享有直接支配和排他的权利，含所有权、用益物权、担保物权（第114条）
- **所有权** — 占有、使用、收益、处分四项权能（第240条）
- **用益物权** — 对他人所有的不动产或动产依法占有、使用、收益的权利（第323条），含土地承包经营权、建设用地使用权、宅基地使用权、**居住权**、地役权
- **居住权** — 书面合同＋登记设立；无偿设立为原则，不得转让、继承；原则上不得出租（第366—371条）
- **担保物权** — 债务不履行时就担保财产优先受偿，含抵押权、质权、留置权（第386条）
- **善意取得** — 无处分权人转让不动产或动产，受让人善意、支付合理对价并已登记/交付的，取得所有权（第311条）
- **建筑物区分所有权** — 业主对专有部分的所有权＋共有部分共有和管理权（第271条）
- **相邻关系** — 不动产相邻各方给必要便利、避免损害的法定义务（第288条起）
- **买卖不破租赁** — 租赁物在承租人按照租赁合同占有期限内发生所有权变动的，不影响租赁合同效力（第725条）

## 合同类

- **要约 / 承诺** — 合同订立的两阶段；承诺生效时合同成立（第471/483条）
- **格式条款** — 为重复使用而预先拟定、订立时未与对方协商的条款；提供方负提示说明义务（第496条）
- **缔约过失责任** — 违背诚信原则在缔约过程中造成对方损失的赔偿责任（第500条）
- **代位权 / 撤销权（合同保全）** — 债务人怠于行使债权或无偿/低价处分财产害及债权人时，债权人可代位行使或请求撤销（第535/538条）
- **债权转让 / 债务转移** — 债权转让通知债务人方对其生效（第545/546条）；债务转移须经债权人同意（第551条）
- **合同解除** — 约定解除＋法定解除情形（第562/563条）
- **定金** — 书面约定、实际交付时成立；限额为主合同标的额20%（第586/587条）
- **违约金** — 可依实际损失请求法院调整（第585条）
- **不可抗力** — 不能预见、不能避免且不能克服的客观情况，部分或全部免责（第180/590条）
- **无因管理 / 不当得利** — 无法定约定义务管理他人事务（第979条）；无法律根据取得利益（第985条）

## 人格权 / 婚姻家庭 / 继承类

- **人格权** — 生命权、身体权、健康权、姓名权、肖像权、名誉权、荣誉权、隐私权等（第990条）
- **隐私权 / 个人信息** — 私人生活安宁与不愿为他人知晓的私密空间、私密活动、私密信息；个人信息处理须合法正当必要（第1032/1035条）
- **离婚冷静期** — 婚姻登记机关收到离婚登记申请后30日；期满后30日内双方亲自申请发证（第1077条）
- **亲子关系 / 收养** — 对亲子关系有异议可请求确认或否认（第1073条）；收养须按法定程序（第1093条起）
- **遗产 / 继承** — 自然人死亡时遗留的个人合法财产；法定继承、遗嘱继承、遗赠扶养协议三种方式（第1122/1123条）
- **遗嘱形式** — 自书、代书、打印、录音录像、口头、公证六种，各有法定要件（第1134—1139条）
- **遗产管理人** — 遗嘱执行人；无则由继承人推选，争议时民政部门担任（第1145—1149条）
- **胎儿利益保护** — 涉及遗产继承、接受赠与等，胎儿视为具有民事权利能力（第16/1155条）

## 侵权责任类

- **过错责任 / 过错推定 / 无过错责任** — 侵权归责三原则（第1165/1166条）
- **自甘风险** — 自愿参加有一定风险的文体活动，因其他参加者的行为受损害的，不得请求其担责（第1176条）
- **自助行为** — 合法权益受侵害、情况紧迫且不能及时获得国家机关保护时，可采取扣留财物等合理措施（第1177条）
- **惩罚性赔偿** — 故意侵害知识产权、产品缺陷致人死亡或健康严重损害、故意污染环境等情形（第1185/1207/1232条）
- **精神损害赔偿** — 严重精神损害可请求（第1183条）
- **好意同乘** — 无偿搭乘中发生事故，应减轻驾驶人责任（驾驶人有故意或重大过失的除外）（第1217条）
- **饲养动物损害 / 高空抛物** — 饲养人担责（第1245条起）；高空抛物禁止，查不清时可能加害的建筑物使用人补偿（第1254条）
