# minfadian · 民法典法条速查

《中华人民共和国民法典》法条速查技能：**1260 条全文按 7 编 84 章及附则共 85 个分册存储**（条文为原文），支持按编/章/条精确定位、生活工作场景检索、高频判断规则速查。

> **轻量定位**：零依赖、纯文本、无 MCP——整个文件夹拷进任何支持 [Agent Skills 规范](https://agentskills.io)的 agent（Claude Code、WorkBuddy 等）即可使用；不支持的 agent 也可把 SKILL.md 当操作手册投喂。同类方案多有 MCP 依赖，本技能刻意保持"拷即用"。

## 文件结构

| 文件 | 内容 |
|---|---|
| `SKILL.md` | 技能入口：使用方法 + 核心规则速览 |
| `chapters/` | 85 个分册（ch01–ch85），逐编逐章存放条文原文 |
| `cheatsheet.md` | 六大生活场景速查表（租房 / 借款 / 婚姻 / 继承 / 侵权 / 合同） |
| `glossary.md` | 法律术语 → 编章定位（善意取得、居住权……） |
| `patterns.md` | 高频适用规则与判断标准，★ 标注与旧法相比的实质性变化（如保证方式反转） |

## 使用场景

- **问具体条文**："诉讼时效是哪条""第586条说什么" → 直接给条号 + 原文
- **问生活/工作场景**："学校租的房子漏水谁负责" → 先查场景表，再定位条文
- **写材料引用法条、审查合同条款**：条文引用一律给条号 + 原文，再附一句白话

## 数据与版本

- 文本：2020 年 5 月 28 日十三届全国人大三次会议通过，2021 年 1 月 1 日施行，共 7 编 84 章 1260 条（第 1260 条同时废止民法通则、婚姻法等 9 部旧法）
- 条文按官方公布文本整理；**如有出入，以国家法律法规数据库（flk.npc.gov.cn）及全国人大常委会公报公布的文本为准**
