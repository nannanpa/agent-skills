# 中华人民共和国民法典 · 法条速查

**通过**：2020年5月28日十三届全国人大三次会议 | **施行**：2021年1月1日 | **规模**：7编84章1260条
**同时废止**（第1260条）：民法通则、民法总则、婚姻法、继承法、收养法、担保法、合同法、物权法、侵权责任法

## 使用方法

- **问具体条文**（"诉讼时效是哪条""第586条说什么"）→ 直接 grep 章文件给原文
- **问生活/工作场景**（"学校租的房子漏水谁负责"）→ 先查 [cheatsheet.md](cheatsheet.md) 场景定位表，再读对应章
- **问法律术语**（"善意取得""居住权"）→ 查 [glossary.md](glossary.md)
- **要判断规则**（"定金最多收多少""保证没约定算哪种"）→ 查 [patterns.md](patterns.md)
- 条文引用一律给**条号＋原文**，再附一句白话

## 提问示例（怎么问、得到什么）

**问条文**："民法典第 586 条说什么"
→ 得到：第 586 条原文＋所属章节＋一句白话（定金不得超过主合同标的额 20%）

**问场景**："学校租的房子漏水谁负责"
→ 得到：先定位租赁合同章＋维修责任条款原文，再按场景给出责任归属的白话说明

**问术语**："什么是居住权"
→ 得到：glossary 定义＋设立条件条文原文（第 366–371 条）＋登记要件提示

**要判断规则**："保证没约定方式算哪种"
→ 得到：第 686 条第 2 款原文（没有约定按一般保证）＋担保制度解释相关条文联动说明

**查合同审查点**："格式条款要注意什么"
→ 得到：第 496 条原文＋格式条款提示说明义务＋合同编通则解释第 10 条的细化口径

## 核心规则速览（最常查的判断标准）

- **民事行为能力**：18周岁为完全（第17/18条）；8周岁以上有限（第19条），8周岁以下无（第20条）；16—18周岁以自己劳动收入为主要生活来源的视为完全（第18条第2款）
- **诉讼时效**：一般3年（第188条），自知道权利受损及义务人之日起算；最长保护20年（第188条第2款）；中止（第194条）、中断（第195条）
- **定金**：不得超过主合同标的额20%，超过部分无定金效力（第586条）；定金罚则双倍返还/不予返还（第587条）
- **违约金**：约定过高可请求法院适当减少、过低可请求增加（第585条；调整口径见[合同编通则解释](jieshi/hetong-tz.md)第64–66条）
- **保证方式**：没有约定或约定不明的，按**一般保证**承担（第686条第2款）——较原《担保法》的重大反转（配套[担保制度解释](jieshi/danbao.md)第25–34条细化适用）
- **借款利率**：禁止高利放贷（第680条）
- **离婚冷静期**：协议离婚需30日冷静期＋30日内双方亲自申领（第1077条；彩礼返还等细则见[婚姻家庭编解释一](jieshi/hunyin-1.md)第5条）
- **居住权**：书面合同＋登记设立，不得转让继承（第367/368条）
- **自愿紧急救助**：造成受助人损害的不担责（第184条）；正当防卫（第181条）、紧急避险（第182条）、自甘风险（第1176条）、自助行为（第1177条）
- **高空抛物**：禁止；查不清时可能由可能加害的建筑物使用人补偿（第1254条）
- **职务代理**：执行法人工作任务的人员就其职权范围内事项以法人名义实施的民事法律行为，对法人发生效力（第170条）——盖章、签字审查常用
- **格式条款**：提供方对免除/减轻己方责任等条款负提示说明义务，未履行可主张不成为合同内容（第496条）

## 异常处理（查不到、问不对时的标准反馈）

遇到下列情况，按固定路径反馈，不要含糊：

| 情况 | 标准反馈动作 |
|---|---|
| 按条号查不到 | 先确认条号是否在 1–1260 范围内；在则按编→章定位重查；仍无 → 明确说"民法典共 1260 条，第 X 条不存在"，并提示是否想要的是某编某章的内容 |
| 场景描述查不到对应条款 | 走 cheatsheet 场景速查表反查；速查表没有 → 明确说"该场景在速查表未覆盖"，给出最接近的编/章，并说明这只是相近条款不是直接规定 |
| 问题不在民法典范围（劳动/公司法/知识产权/行政/刑法） | **明确指路**："这属于《劳动合同法》调整范围，本技能不收录"——不要拿民法典条文硬答 |
| 涉及司法解释的适用问题 | 先查对应解释（见"配套司法解释"节）；解释也未覆盖 → 明确说"正文与 7 件解释均未涉及"，建议咨询执业律师 |
| 条文有多个相关项拿不准 | 列出全部相关条号＋原文，说明差异，让使用者自选；不要擅自替使用者选定唯一答案 |

**原则**：宁可明说"没有/不覆盖"，不拿相近条文冒充答案。

## 范围与限度

- 本技能收录**2020年公布版民法典原文**＋最高法配套司法解释 **7 件全文**（总则编、担保制度、合同编通则、婚姻家庭编一/二、继承编、时间效力，见"配套司法解释"节）；其余专门解释（如人脸识别规定、环境侵权解释）与指导性案例**未收录**
- 劳动关系（《劳动合同法》）、公司事务（《公司法》）、知识产权单行法、行政法**不在民法典范围内**，相关问题应提示适用专门法律
- 司法解释与正文冲突时（新旧衔接），先查[时间效力规定](jieshi/shijian.md)
- 本技能供学习与材料参考，不构成正式法律意见

## 反模式（错误用法对照）

| ✗ 错误用法 | 为什么错 | ✓ 正确姿势 |
|---|---|---|
| 拿它查劳动纠纷、公司事务 | 不在民法典范围，硬答必错 | 劳动→《劳动合同法》；公司→《公司法》；本技能会明确指路 |
| 把输出当律师意见用于决策 | 本技能是学习与材料参考工具 | 正式法律事务咨询执业律师；重要材料对照权威文本复核 |
| 只引条号不核司法解释 | 很多高频问题的答案在解释里（如保证方式、违约金调整） | 引条号后连查配套解释对应条文（见"配套司法解释"节） |
| 用生活语言直接 grep 条文 | 生活用语与法条术语有距离（"房租漏水"vs"租赁物维修"） | 先查 cheatsheet 场景速查表翻译成法律场景，再定位条文 |
| 引用已废止的旧法条文（民法通则/合同法等） | 民法典施行后旧法已废止（第 1260 条） | 本技能只收民法典现行文本；遇到旧法引用提示已废止 |
| 把"核心规则速览"当完整规则 | 速览只是最高频项，不是全部 | 速览定位方向，准确内容以分册原文为准 |

## 常见问题（FAQ）

- **记不清条号怎么查？** 不用记。按"七编索引"从编到章定位，或用 cheatsheet 场景速查表从生活场景反查——问场景比问条号更好用。
- **收录了哪些司法解释？** 7 件配套解释全文（总则编、担保制度、合同编通则、婚姻家庭编一/二、继承编、时间效力），见"配套司法解释"节。其余专门解释与指导性案例未收录。
- **劳动纠纷、公司事务、专利商标能查吗？** 不在民法典范围内，会提示改用专门法律（《劳动合同法》《公司法》等单行法）。
- **能当法律意见用吗？** 不能。本技能供学习与材料参考；正式法律事务请咨询执业律师。
- **写材料引用法条，怎么引用最稳妥？** 条号＋原文＋一句白话；重要材料建议再对照全国人大法工委的权威文本复核一遍。
