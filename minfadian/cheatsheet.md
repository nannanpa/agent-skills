# 场景速查表（遇事先定位置，再读章文件取条文）

## 一、签约 / 合同审查（工作最常用）

| 情形 | 判断点 | 查 |
|---|---|---|
| 对方是公司，谁签字有效 | 法定代表人职务行为（第61条）、职务代理（第170条）；合同书自签名/盖章/按指印时成立（第490条） | ch03、ch06、ch32 |
| 合同没写全 / 只发了订单确认 | 一方履行对方接受即成立（第490条第2款）；要约承诺规则（第472—483条） | ch32 |
| 对方用了格式合同 | 免责/限责条款是否加粗提示；未提示可主张不成为合同内容（第496条） | ch32 |
| 合同效力存疑 | 无效情形（第153/154条）、可撤销情形：重大误解/欺诈/胁迫/显失公平（第147—151条） | ch06、ch33 |
| 该不该收定金 / 收多少 | 上限＝标的额20%（第586条）；违约时择一适用定金或违约金（第588条） | ch38 |
| 对方违约怎么办 | 继续履行/补救/赔偿（第577条）；违约金过高可减（第585条） | ch38 |
| 想解约 | 约定解除＋法定解除九种情形（第563条）；解除通知到达生效（第565条） | ch37 |
| 对方快没偿付能力了 | 代位权（第535条）、撤销权（第538条）、不安抗辩（第527条） | ch35、ch34 |

## 二、借贷与担保

| 情形 | 判断点 | 查 |
|---|---|---|
| 借条怎么写 | 借款合同书面（自然人之间另有约定除外，第668条）；利息预先扣除按实际数额算本金（第670条） | ch42 |
| 利息上限 | 禁止高利放贷（第680条）；具体上限按司法解释 | ch42 |
| 别人担保 / 让人担保 | ★没写"连带"就按一般保证（第686条）；保证期间默认6个月（第692条） | ch43 |
| 房子抵押 | 抵押不转移占有；抵押期间可转让抵押财产（第406条）；须登记设立（不动产，第402条） | ch27 |
| 欠钱拖着不还 | 诉讼时效3年（第188条）；**每年书面催收并留痕**可中断时效（第195条） | ch09 |

## 三、不动产 / 房屋

| 情形 | 判断点 | 查 |
|---|---|---|
| 买房卖房 | 买卖合同规则（第595条起）；不动产物权登记设立（第209条） | ch39、ch12 |
| 房子出租 | 租期最长20年（第705条）；买卖不破租赁（第725条）；承租人优先购买（第726条） | ch44 |
| 给老人设"居住权" | 书面＋登记设立，不得转让继承、原则不得出租（第366—369条） | ch24 |
| 装修漏水泡了楼下 | 相邻关系（第296条）；侵权赔偿（第1165条） | ch17、ch84 |
| 小区电梯广告收益、车位 | 共有部分收益归业主（第282条）；车位优先满足业主需要（第276条） | ch16 |
| 物业费 / 物业服务 | 物业服务合同章（第937条起） | 物业章 |

## 六、公文写作引用法条（行政机关材料场景）

- 引用格式：**《中华人民共和国民法典》第X条**；正文转述后括注条号
- 合同盖章效力 → 第490条；职务代理 → 第170条；法定代表人 → 第61条
- 事业单位法人 → 特别法人（第96—97条）
- 格式条款提示义务 → 第496条（学校发的协议、告知书类文本注意）
- 诉讼时效 → 第188条（涉及历史遗留债权债务的表述）
- 个人信息 → 第1035条（涉及师生信息处理场合）

## 七、不归民法典管的事（别在这里找）

劳动合同与社保 → 《劳动合同法》《社会保险法》｜公司设立与治理 → 《公司法》｜行政处罚与政府信息公开 → 行政法各法｜专利商标著作权 → 知识产权单行法｜税 → 税法体系。这些领域的合同问题仍可参照民法典合同编通则，但专门法优先。
