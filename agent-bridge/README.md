# 智能体通讯桥（agent-bridge）

零常驻的 agent 间消息桥：一个纯标准库 Python 脚本＋一个共享目录，即可让多个 agent 互递任务与回执。无 .app、无常驻进程、无宿主注入；由人或定时任务拉起，查收件箱、按线程限三领信、把信全文打到 stdout。

## 能做什么

- 给另一个 agent 递任务/审查请求，不手工复制粘贴。
- 停函收口：回执即终／协商限三／超限与缺字段信进 `pending-人工/` 由人裁决。
- 收件箱可配置：`--ws <目录>` 或环境变量 `AGENT_BRIDGE_WS`，换机不必改代码。

## 用法

```bash
python3 bridge.py wb     # 领 B 端写的信（文件名 dsh-*函-*.md）
python3 bridge.py dsh    # 领 A 端写的信（文件名 wb-prompt-*.txt；--side 前缀等价）
python3 bridge.py dsh --ws /path/to/inbox          # 指定收件箱
AGENT_BRIDGE_WS=/path/to/inbox python3 bridge.py dsh   # 或走环境变量
```

发信＝往约定收件箱写一封符合消息协议的 md/txt（〔线程〕〔类型〕＋四段，≤10 行，对照样例见 `sample-letter.md`——注意样例文件本身不能直接投递，须改名且一文件一信）。收信＝人工或定时跑脚本，按 stdout 的信全文处理。无信静默退出。

## 边界与已知限制

- 只传消息不交会话；敏感内容不落盘。
- 当前不接宿主 hook，脚本不会被自动拉起；自动收信靠定时任务扫箱。
- 空闲唤醒受宿主封闭性限制，非本桥可解。
- 无 `--only` 单封过滤；无重试与超时；并发互斥依赖 fcntl，Windows 等无 fcntl 环境降级为无锁运行（会提示，勿并发跑两个实例）。
